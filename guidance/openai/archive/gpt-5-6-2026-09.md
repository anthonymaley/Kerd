# OpenAI GPT-5.6 family profile

The three tiers share the outcome-first prompting family and supported effort
range. Tier selection remains part of dispatch:

- **Sol** — complex professional work and capability-sensitive execution.
- **Terra** — balance intelligence and cost.
- **Luna** — cost-sensitive, high-volume and well-bounded work.

Those are starting roles from official model positioning, not proof for any
Kerd task class.

```yaml
- id: outcome-first
  applies_when: always
  guidance: Compile objective, success, evidence, guardrails, authority, and stop conditions; omit process detail unless the path is required.
  basis: provider-guidance
  source: official_sources[0]
  evaluation: pending
  review_trigger: first GPT-5.6 pilot or source change
- id: tier-by-eval
  applies_when: choosing Sol, Terra, or Luna
  guidance: Start with the cheapest eligible tier, or capability-first for high-consequence unknown work, then retain the tier only when matched evals justify it.
  basis: provider-guidance
  source: official_sources[1]
  evaluation: pending
  review_trigger: model-tier sweep, task-class change, or source change
- id: effort-native
  applies_when: selecting deliberation depth
  guidance: Set reasoning effort in model configuration; do not simulate it with a long reasoning script. Increase only when evaluation shows a measurable gain.
  basis: provider-guidance
  source: official_sources[0]
  evaluation: pending
  review_trigger: effort sweep or source change
- id: native-tools-and-schema
  applies_when: tools or structured output are available
  guidance: Use native Responses tools, tool descriptions, and Structured Outputs. Keep only cross-tool policy and task evidence in prompt prose.
  basis: provider-guidance
  source: official_sources[0]
  evaluation: pending
  review_trigger: platform integration changes or source change
- id: cache-shape
  applies_when: repeated prompts share a stable prefix
  guidance: Keep stable instructions before dynamic task context and record cached-input tokens separately.
  basis: provider-guidance
  source: official_sources[0]
  evaluation: pending
  review_trigger: cache telemetry comparison or source change
```

Kerd-owned tier example:

```yaml
dispatch_candidates:
  - model: gpt-5.6-luna
    when: envelope is bounded, mechanically verifiable, and low consequence
  - model: gpt-5.6-terra
    when: task needs balanced judgment and tool use
  - model: gpt-5.6-sol
    when: ambiguity or consequence makes capability the primary constraint
```

The pilot must test these hypotheses; Conductor never treats tier names as the
answer without task evidence.
