## Gotchas

- **The conductor marker can never carry a sitting's open time.** It holds one
  line, so it reports the LAST phase, while the open time is a property of the
  FIRST. A design-heavy session reproduces this whether it plans once or five
  times. The test before handing over an open time is not *"did we plan twice?"*
  but *"is the `execute` stamp plausibly when this sitting began?"*
- **`cd` inside one Bash call leaks into the next one.** Working directory
  persists across tool calls even though shell state does not; a later relative
  path resolved against the wrong root and failed naming a path nobody wrote.
- **A rendered diagram must be looked at, because nothing else checks it.** SVG
  text does not wrap and does not visibly clip — it runs past its box and out of
  the drawing, with no error anywhere. Four diagrams today produced three
  text-overflow defects and two edge-crossing defects, every one invisible until
  the PNG was opened.
