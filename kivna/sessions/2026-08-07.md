## Gotchas

- **A `## Risk ledger` section must be table-only.** The parser treats every
  non-blank line in the section as a row, so a closing paragraph comes back as
  "rows 5-9: expected 8 columns, found 1". Same family as the v0.83.1
  fence-awareness fix. Put commentary in its own section after the table.
- **`unmitigated` is not a legal ledger state.** The closed set is
  `countermeasure - permanent`, `countermeasure - temporary`, `accepted`,
  `accepted unknown`, `fatal` — the machine enforcing "a risk without a
  countermeasure is a BLOCKER". An honestly-unresolved risk is `accepted
  unknown` with a review trigger, not `unmitigated`.
- **Grounding references must not be wrapped in backticks.** AU5 reports "does
  not resolve" for `` `path` `` even when the path exists. Plain paths only.
- **The sitting's open time is not always the `execute` stamp.** The v0.89.0
  rule says the execute stamp is the sitting's open time; this sitting opened
  at 08:28 (orient marker) and did not reach execute until 09:25 — nearly an
  hour of framing. Using the execute stamp would have labelled a 105-minute
  sitting as 48. Both stamps are machine-produced and same-turn, so the honest
  range uses the earliest marker written this sitting, not the execute one.

## Insights

- **The frame gate caught a stale premise by refusing a missing section.** No
  cleverness involved: `## Value` was required, could not be written honestly,
  and the attempt to write it surfaced the problem. The cheapest drift detector
  in the system is a required declaration that someone must fill in.
- **Asking for the plain-English version found more than any audit did.** Four
  gaps came from tooling and measurement; seven came from describing the flow

- **The fix for gaps 1-7 was pointing at artifacts that already existed. That
  approach cannot work for gaps 10-12**, because there is nothing to point at —
  which is the difference between losing code context and losing human context,
  and the reason slice 2 is a harder problem than slice 1.

## Gotchas

- **The entry gates report requirements cumulatively.** Rendering them
  literally per stage makes every stage look identical. Show the delta.
