## Gotchas

- **`cd "$VAR" 2>/dev/null || exit 0` is a false safety net under `set -u`.** Unset `$VAR` aborts during expansion (exit 1 + stderr) before the redirect or `|| exit 0` can act; empty `$VAR` is worse-quiet (`cd ""` succeeds, hook runs in the inherited cwd). Guard existence before the deref. shellcheck does not flag this — an empirical probe found it. Now in `docs/playbook.md`.
- **Run characterization tests RED before fixing.** The first red run caught two of my own assertions that mis-modeled correct hook behavior (first-message capitalization; `next_skill` keeping its leading slash). Green-only would have let me "fix" correct code to match wrong tests.

## Insights

- **The linter and the probe find different bugs.** shellcheck flagged only style + one brace warning; the actual exit-1 crash on unset env var was invisible to it and only showed under empirical execution. Lint is necessary, not sufficient — the behavioral probe is where the regression class actually lived.
