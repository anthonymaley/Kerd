## Gotchas

- **A daemon never loads a TUI, so `thread/read` reports every TUI as
  `notLoaded`.** "Not loaded" is the normal state of a session a person opened,
  not "offline". A refusal keyed on it refuses every TUI.
- **`codex queue` declares its own `-C/--cd`; a `head -20` of its help cut it
  off.** Read help in full before asserting a flag is global-only.
- **UUIDv7 prefixes collide by timestamp.** Threads spawned in the same second
  share eight hex characters; a truncated display shows duplicates that are not.
- **`git add` aborts the whole command on one unmatched pathspec** — a staged
  set can be an unmodified `R100` rename with none of the work in it. Read the
  staged diff, not the command's silence.
- **A transient `.git/index.lock` from another session fails a commit outright;
  the staged set survives.** Check for a live git process, confirm the lock is
  gone, retry; never delete it blind.
- **A prose mention of both request markers parses as a reply of one word**
  unless retrieval requires them to delimit lines and the position is judged
  before trimming to the marker.
- **A subagent review of your own build finds nothing by reading; it finds
  things by testing the hazards a prior reviewer named.** The one real bug the
  self-review caught came from a guard test, not from re-reading.
