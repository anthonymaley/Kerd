## Gotchas

- **A machine that sleeps kills a long-running agent mid-write.** It happened
  twice. The composer survived because its work had already landed; the view
  spike lost everything because it was still thinking. **For any long agent
  task, instruct it to write to disk early and often** — the difference between
  an interruption and a restart.
- **`## Graveyard` appears in prose as well as as a heading**, so splitting a
  register on that string silently puts every requirement on the wrong side.
  Split on the heading (`\n## Graveyard`), not the substring. Cost: one wrong
  verification that reported 0 live requirements.
- **A subagent will invent an illegal front-matter value to fill a required
  field** — the view spike wrote `stage: findings`, which is not a legal stage,
  and it reached the audit. A spike's *output* is not a rung and does not belong
  in the funnel directory at all.
- **An acceptance test must quote the source literal, not the rendered output** —
  carried from yesterday and confirmed again today.

## Insights

- **Writing and parsing are different tests, and we had only been running one.**
  The format was validated twice by having agents write in it and audited twice
  for fidelity. All four passes missed all three defects a parser found within an
  hour. **Nothing had tried to read it mechanically until the view existed.**
- **All three defects produced plausible wrong answers**, one fabricating four
  phantom dependencies that looked entirely genuine. That is why they survived
  review: **a plausible answer is believed where an error is seen.** The rule
  that came out of it — *ambiguity is refused, never guessed* — is the one
  generalisable lesson of the day.
- **The strongest evidence for a fix is a stranger reproducing it.** The
  fingerprint recipe was implemented independently three times — by its author,
  by a test agent given only the document, and by the conductor — all landing on
  the same twelve characters. That is a different kind of confidence from
  reviewing the prose.
- **The producer caught every over-read, and the models caught none of them.**
  Four times: "approval" inflated into authority, an ADR observation into a
  position, "maybe lifecycle" into a correction, and a checklist the evidence
  killed proposed for demotion instead. Each was found by him reading what was
  written. The adversarial tier is not a substitute for the producer reading the
  artifact.
- **The register had almost no rationale and nobody knew.** 44 of 51 requirements
  shared one identical provenance string where a reason should have been. A
  validator, a hash discipline and a promotion beat had been built on top of it.
  **The machinery was real; what it was protecting was thinner than it looked.**
- **Every decision today removed something** — a field, a taxonomy, a type list,
  eight links, thirteen requirements — and the thing that survived each cut was
  smaller and load-bearing. A perspective instead of a checklist; one
  distinction instead of twelve types; one link instead of nine.
