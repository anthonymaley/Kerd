## Insights

- **The A/B cold-pickup quiz is a cheap, reusable harness for read-set changes**: derive the questions adversarially from the content you're removing, give each set to a fresh subagent with a strict "NOT FOUND, don't guess" rule, and grade against ground truth. Minutes of work, and it names exactly which removed content wasn't a duplicate.
- **Validating the new design found a bug in the current one.** The quiz's single miss wasn't a lean-set failure — it was a five-day-old silent slip in the existing switch-out. Validation pays even when the proposal passes.
- **"Efficient but complete" dissolves once state, work, and history stop sharing files.** The RDF question was really a dedup question: the format was never the cost — the copies were.
