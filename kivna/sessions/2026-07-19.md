## Gotchas

- **Focus mode makes mid-turn text invisible — gate messages must carry their content.** A skill that ends a turn on an approval question can collapse to a content-free "execute the plan?" under focus mode + brevity rules. Mirrored to `docs/playbook.md`.
- **Renaming a per-repo state file silently disables the feature everywhere the old file lingers.** The `focus → pair` rename (v0.64.0) changed what the global hook greps for (`kivna/.pair`); 3of3 still has `kivna/.focus`, so partner mode there has been silently off since the rename — no error, no signal, the hook's guard is simply false. Mirrored to `docs/playbook.md`.

## Insights

- **A brevity rule and an invisibility mechanism compose into silence.** Neither the question-formation gate nor focus mode was wrong alone: the gate trimmed noise, focus mode hid scaffolding. Together they deleted the deliverable. When two "make output leaner" mechanisms stack, check what survives their intersection — the fix wasn't to relax either, but to name what must never be trimmed (the findings) and where it must live (the final/gate message).
