## Gotchas

- **A cached image read silently defeats the only check a diagram has.** The
  standing rule is that nothing checks a rendered diagram but a person opening
  the PNG. Re-reading a PNG immediately after re-rendering it returned the
  *previous* image, showing an overflow that had already been fixed — and would
  equally have hidden one that had not. The byte count was identical, which made
  it look correct. Re-read only after confirming the file actually changed, and
  treat an unchanged size on a changed source as a cache hit rather than a no-op.
- **`view_fingerprint` takes file CONTENT, not a path.** Passing paths produced
  two plausible twelve-hex fingerprints that were silently wrong. Caught only

## Gotchas

- **A doc quoting a machine string must be checked against the RUNTIME value,
  never a source grep.** `kit.py` builds its refusal literals as f-strings split
  across source lines, so `grep "Scope declares a legal rigor level (…)"` returns
  nothing even though the string is emitted exactly. It reads as a genuine MISS.
  Construct a fixture and read the emitted line back instead.
- **`grep -c` and `grep | wc -l` exit non-zero on a zero count, which is the
  PASSING case for a purity check.** An `&&` chain therefore truncates silently at
  the first passing assertion. Four of sixteen verify blocks in this build were
  wrong about grep mechanics rather than about what to check; use `;` separators.
- **A retired name inside a split string literal is invisible to every grep.**
  `f.step("9", "GOAL\nGATE", …)` survived a whole sweep because no search for
  `GOAL GATE` can match it. Unsplit `\n` and `\t` escapes before matching.
- **Running a generator to "check it still works" rewrites its dated output.**
  Several `gen_flow_*.py` scripts write dated records and have no dry-run mode;
  one also merges annotations and re-marks blue deltas. Edit the source, do not
  execute it, when the output is a historical record.
- **The bare `progress.py` render writes the committed trio.** Running it to
  inspect the board mid-build dirties three files the assembly step owns. Use the
  `selftest` subcommand for inspection.
