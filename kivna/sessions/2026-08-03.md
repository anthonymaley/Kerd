## Gotchas

- **Excalidraw reassigns every element id on paste.** An ownership scheme based on id patterns fails on the first round trip — after one paste my own 209 elements read as foreign. Use `customData` instead; it survives the clipboard. Mirrored to `docs/playbook.md`.
- **zsh does not word-split unquoted variables.** A `for x in $VAR` loop over a space-separated string runs once with the whole string. Use an array. Cost a bogus "every skill is an orphan" result before it was caught. Mirrored to `docs/playbook.md`.
- **`find ~ -name ...` without a depth limit will hang past the command timeout.** Scope searches to specific directories. Mirrored to `docs/playbook.md`.

## Insights

- **The useful mechanisms already existed, aimed at a different problem.** The `low` switch modifier (built for token budget, wanted for context hygiene), the self-correction reporting rule (built to distinguish "guard worked" from "got lucky", and it is the nearest thing to a degradation signal), conductor's pre-flight inventory (an entry gate that exists at exactly one rung). Finding the second caller for an existing mechanism is cheaper than building a new one — and the tooling catalogue exists to make those second callers visible.
- **Generating artifacts unseen is a defect, not a caveat.** Two diagrams shipped and validated before anyone looked at them; the first render immediately exposed a caption sitting on top of a box. The checker had a blind spot shaped exactly like the thing I could not see. Both a bound-text and a collision check now run on every generation, and the collision check has caught two faults since.
- **Almost every correction Tony made was a *relationship* between functions, not a property of one** — design approval gates the loop, the loop requires CI, the evidence column needs a consumer, the conformance step reads what PRODUCT declared, testing is decided once and applied many times. None would surface from gathering requirements function-by-function in isolation, which is the argument for a full shallow pass over a deep one on three.
