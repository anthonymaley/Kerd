## Found at design time

The freshness anchor must not be HEAD — the commit storing the page
moves HEAD, so a HEAD stamp deadlocks the staleness compare
permanently. Anchor is model-derived (newest landed-piece commit + a
state fingerprint), converging by construction. Same self-reference
class as push-wiring's killer, caught before a line was built.
