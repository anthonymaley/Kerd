## Found at design time

Grandfathering-for-free was refuted: `progress_kit.board_for`
re-derives `gate.py route` for every slug on every render, and route
inputs are cumulative — a new design-rung input row is retroactive in
effect. The frame's no-retrofit clause was amended in the same sitting
(Tony's key): uniform rule, honest one-line retrofit of the three
existing docs, landing in the same commit as the rule. A level is one
falsifiable value — it cannot be hollow the way a reconstructed
reading list can.
