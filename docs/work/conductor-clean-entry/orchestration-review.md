<contract>
Without selecting Conductor, ordinary host work remains ordinary. Conductor is
explicitly selected through a request to use/guide the workflow, an approved
Switch recommendation, or continuation of established Conductor work—not merely
because someone says build an app. It then assesses every task, including small
tasks and newly emerging ones, for composer work, contributors, controller work
and model/effort suitability. Reuse settled assessments; no staffing ceremony on
every response. Composer can be this session or a useful delegated contribution,
not a compulsory extra agent. Useful independent jobs are assigned, tiny or
coupled jobs have concrete inline reasons. Startup shows the current pair with
its evidence status and a proportionate work grid, even if no worker launches.
Prompt preparation consults applicable provider/model guidance before dispatch,
preserves outcome/permissions/checks, retains a safe brief and distinguishes
actual preparation, submission, return and assessed results. Unknown model/effort
doesn't become guessed defaults or automatically block safe work. No settings
or main-session model changes without authority.
</contract>
