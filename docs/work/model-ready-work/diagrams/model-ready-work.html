1 · Understand

Describe the idea

Speak naturally. Conductor retrieves known facts, reflects its understanding, and asks only what can materially change the work.

→
2 · Shape

Define the direction

Show the outcome, experience, connected parts, flow, measures, guardrails, authority, resources, and stopping point.

→
3 · Person

Approve once

Confirm the experience and outcome. This fixes the direction without freezing the implementation route.

→
4 · Conductor

Prepare each job

Select a coherent slice, fresh context, appropriate model, effort, and peer review. Prove no obligation was lost.

→
5 · Autonomous

Enter the loop

Conductor continues without routine user input while the approved direction remains possible and safe.

6 · Build

Create the result

Bounded model jobs choose their methods inside the approved direction and guardrails.

→
7 · Peer review

Judge independently

A peer or different model checks the original measures from admissible evidence. The builder does not grade itself.

→
8 · Improve

Correct and retest

Failed measures return to Build. Each retry must materially respond to the evidence, not repeat the same attempt.

→
9 · Prove

Complete honestly

Every measure passes independently. After three materially different failures on one measure, Conductor changes route or raises one consequential decision.

If a run fails, repair only what failedRequirement → brief · Context → context pack · Selection → model or effort · Execution → targeted retry · Proof → missing evidence · Product → feature or slice. Never make every future prompt longer by default.

Accessible description: Kerd holds any kind of durable work in a project repository. Switch preserves continuity. Conductor first understands the person's idea, then shapes a visual direction containing the outcome, experience, connected parts, measures, boundaries, authority, resources, and stopping point. The person approves that direction once. Conductor selects focused model jobs and runs Build, peer review, proof, and improvement without routine interruption. The builder never grades itself. Failed measures return to the loop; three materially different failures against the same measure return routing control to Conductor. Conductor completes only when every agreed measure independently passes and the requested stopping point is reached.
