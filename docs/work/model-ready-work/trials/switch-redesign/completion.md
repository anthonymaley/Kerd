## The four actions

| Need | Say | What happens |
| --- | --- | --- |
| Start the next sitting | Switch in | Bring in authorized repo updates, read the named current records, recover the actual position and continue authorized work. |
| Finish this sitting | Switch out | Save work/history, remove evidenced completions from active lists, leave useful reading directions, and commit/push under the agreed authority. |
| Move active work | Switch to my laptop | Save the exact unfinished place, verify the agreed GitHub revision, release the owned source and supply the destination pickup. You open the destination session. |
| Continue a long build | Roll | The managed build saves at a safe point, starts a fresh owned worker and continues the same agreement without a routine go-ahead. |

If you are only reconnecting to the same Studio session through SSH/tmux, no
handoff is needed. An arbitrary open user terminal is not a managed worker:
Switch must disclose when it cannot close/restart that host. Saved files are not
proof of process exit or permission to start duplicate work.
