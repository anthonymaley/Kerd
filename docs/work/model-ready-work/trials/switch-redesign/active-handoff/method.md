# Active handoff: local rehearsal

Next after the prepared-reader trial. This test uses two disposable checkouts and
a local bare Git remote, never GitHub, live Seinn or an existing user session.

Prove this order with real managed workers:

Build a useful piece → save the exact unfinished place → verify it at the local
remote while the source worker still exists → confirm owned source shutdown →
load the same revision in a second checkout → continue the agreed work there.

The task is a small readable preview of the prepared-pickup packet. It should show
what will be loaded without dumping memory text or falsely declaring restoration,
budget success or user approval. Source writes its implementation and freezes;
destination finishes verification and usage. This is a deliberate mid-work test
boundary, not a context-pressure trigger or optimal work-splitting claim.

Use the existing gpt-5.6-sol/high route, supported by prior bounded coding trials.
No model benchmark or cost optimum is claimed. No trial resource cap is set.
Workers may edit/test only their own checkout; no networking, Git writes, other
agents, native history or outside-project writes. The controller alone creates
the fixture, commits named files, pushes to the local bare remote and dispatches.

The existing adapter closes its worker after a completed turn. A trial-only
observer intercepts that completed-turn event to perform the named local save
before adapter shutdown. It does not modify the installed adapter or create a
general product lifecycle API. The observer validates the saved-place response
and known event identity; any uncertain result prevents destination dispatch.

Success needs actual source artifacts, matching saved revision, distinct fresh
sessions, remote verification before source shutdown, shutdown before destination
start, unchanged agreement/constraints, retained failure state and independent
assessment of the finished artifact. Controller reruns artifact tests. Missing
evidence is not a pass. Native IDs stay in private Git metadata.

Important limit fixed before running: save failure still causes the existing
adapter's cleanup to stop its owned worker. Local files and the outer controller
remain recoverable, but this does NOT satisfy the intended “failed save retains
the source session” behavior. No automatic To acceptance follows from this happy
path rehearsal. Arbitrary interactive hosts and two-device release remain open.

Protocol basis: [official OpenAI App Server documentation](https://learn.chatgpt.com/docs/app-server),
opened 2026-09-07. Turn completion reports a model-turn outcome, not proof that
the process has exited. This test uses actual local process observations for exit.
