## Outcome and pass conditions

Restore current position, last completed work, next obligation, outstanding
producer decision and relevant authority from the actual saved files. Use the
complete candidate Switch skill and In/Out reference, with targeted project
retrieval. No whole archive by default. No invented active build or routine
permission question. Claude independently checks the answer against source files.
All tracked/untracked project state must remain unchanged.

The existing agreed target is no more than 8,000 added input tokens and 5% of
observable usable context. Measure the local-only pickup working set, including
skill/reference instructions, request, selected memory, tool output and generated
context. This does not measure subsequent feature work or GitHub synchronization.
Clone setup and experiment telemetry are controller setup, outside model pickup.

## Measurement fixed before seeing results

Run minimal control → pickup → identical minimal control as three fresh native
Codex sessions in the same checkout, model gpt-5.6-sol, high effort, same read-only
app-server route. Controls must use no tools or project reads. The pickup prompt
includes the real skill and reference texts, not a shortened imitation. Actual
submitted prompts and sanitized numeric observations stay in this folder.

Use each notification's **last** request, never summed billing tokens. Let B be
the smaller first-request input count of the two controls. Report:

- Host-inclusive peak input and peak total context for the pickup.
- Estimated added input = peak pickup input minus B.
- Conservative estimated added context = peak pickup total minus B (includes
  the final answer rather than subtracting it away).
- Added context / the reported usable window; both 8,000 and 5% must hold.
- Control spread, elapsed time, full read manifest and independent assessment.

These are matched-run differential estimates, not exact token attribution or a
statistical confidence interval. If controls drift materially, native usage/window
is unavailable, compaction occurs, reads are incomplete, or restoration fails,
do not award a budget pass. A local pass does not certify every host/model/project,
an end-to-end GitHub pickup, or improvement over old Switch (no matched old-Switch
baseline is being run). Unknown historical facts remain unknown.

Protocol source: [official App Server events](https://learn.chatgpt.com/docs/app-server),
opened 2026-09-07. Official docs establish usage updates and completed tool items;
installed schemas and actual notifications establish concrete numeric fields.
The experiment records only ordinary command output/tool metadata privately,
never reasoning content, and does not feed native histories into the reader.
