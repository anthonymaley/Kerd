Kerd · retire four skills · Conductor · Shape · proposed, not agreed

Install what the front page says

Kerd's public page shows eight skills. Installing the plugin gives you twelve: Drive, Lorg, Interrogate and Pair were ruled out on 2026-09-18 and 2026-09-19 and are still shipped. Proposed: one release takes the four out, with Pair's session hook, and leaves the checks, the ladder and the risk-ledger format exactly as they are.

What changes for someone installing Kerd

  • They get the eight skills the page describes and nothing else.
  • /kerd:drive, /kerd:lorg, /kerd:interrogate and /kerd:pair stop existing. That is the breaking part.
  • Pair's sentence is no longer added to sessions where it was switched on (Kerd and 3of3 today).

Found on 2026-09-19, and it shrinks the job

  • The ruling tied Interrogate's removal to a ladder and gate cleanup, from reading a guide, not the code.
  • Traced once: the checks define the risk-ledger format themselves, and nothing in the check tools, hooks, tests or CI names Interrogate.
  • So Interrogate can leave without touching the checks. One search, not yet confirmed by a test run with the skill gone.

Not in this release

  • Any change to the ladder, the checks or the ledger.
  • The old drawings that still name retired skills.
  • The launch-plan rewrite, the install-command test, rolling without publishing.
