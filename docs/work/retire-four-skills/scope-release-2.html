Kerd · retire the ladder and ledger · Conductor · Shape · proposed, not agreed

One way to keep work honest

Anthony's ruling, 2026-09-19: nobody wants a machine that refuses their work, and this level of risk ledger is not needed. What is wanted is the sketchbook that becomes a spec, a score to check the build against, and risks kept in view. Proposed: one release removes the ladder's machinery and its public promises, gives Conductor a plain place for risks, and leaves the old records where they are as history.

What changes for someone using Kerd

  • Conductor stops asking a project which step a work item is on. That check shipped on 2026-09-18 and goes.
  • The sketchbook gains a short list of risks to keep in view, read back before Ready.
  • The "Checks that can say no" guide, its picture and its line on the website go.

What changes inside Kerd

  • About 8,700 lines of check, register and matrix tools go, with the progress board and old diagram generators.
  • CI drops from eleven steps to three: skill tests, hook tests, release rules.
  • The release rules check is lifted out into its own small file first, so every push stays protected.

Not in this release

  • Moving or deleting the old records. They stay, unpoliced.
  • Closing the Backlog rows that were ladder debt. That is a tidy at the next session close.
  • Rewriting the launch plan.
