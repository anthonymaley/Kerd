## Checks to make

- Normal approval explicitly invokes start/resume with selected scope, actual
  authority and work pointer; no duplicate approval or intake.
- A factual answer, deferral or human check does not authorize an agent build.
- Rolling Out/In retains agreement, next action, evidence and failure history,
  reconciles contributors and waits for verified source release before dispatch.
- Context-triggered worker succession uses fresh identity and no user prompt;
  review and blocked states return to the controller, not an acceptance claim.
- Report separately: fixtures, model behavior, native worker rollover, and whole
  controller/TUI rollover. Do not claim one proves another.
