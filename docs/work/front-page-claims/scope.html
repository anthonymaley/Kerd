The site, and the pictures

Four pages and twelve drawings, opened in a real browser for the first time on 2026-09-20.

The pages themselves hold up: nothing overflows, no dead links, no console errors, at desktop and phone width alike. The drawings do not. On a 390px phone every label in every picture falls under 12px; the smallest, on the opening drawing, renders at 6.96px. The standing suspicion said "near 8px" and was understating it. Still not established: whether the site is published anywhere a stranger could reach — the repository builds no site, it only stores one.

The trial route

The page offers claude --plugin-dir as a way to try a version without committing to it. It has never been run. What it promises splits in two:

✕Known wrong “Nothing is installed or disabled globally.” True of plugins and marketplaces. Not true of every trace: the command writes a usage row into the reader's own ~/.claude.json. A wrong sentence, not a broken mechanism — no test in the repository could find it.
○Never run “A same-name local plugin takes precedence for that session only.” Plausible and unverified. Settling it means running the command and watching which version actually answers — the half of this work that touches machine state.
✕Read · three more wrong

Everything else the page claims

Fifty-five falsifiable claims. Around twenty-five have never been run. Three are wrong, and one of them is the same defect that was just fixed.

Roll back by pinning to 716a099. That commit's manifest still declares the SSH address 0.142.1 was released to remove. The fix is three sections above; this sends the reader straight back into it.
"Kerd keeps four kinds of file… all four are ordinary Markdown." Not in this repository. There is tracked JSON, rendered HTML and SVG, hidden state, and a vault outside the project entirely. The section whose job is disclosure is the one that understates.

And the guarantee over all of it — "nothing below claims more than the repo can show" — is falsified by its own page, three times.
