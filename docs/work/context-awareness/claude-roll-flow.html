How an unattended Claude Roll run saves its place at 65%

Only for unattended Roll runs. In interactive sessions nothing changes: you choose when to Switch Out.

What stops a run: missing usage or window, a changed tool set, model or folder, an extra turn, a permission denial, a hook that blocks, a second result, or cleanup that can't be verified. Known limit: one very large tool result can pass 65% before the message lands. Not in v1: live control and handing a Claude run to another device (Codex only).
