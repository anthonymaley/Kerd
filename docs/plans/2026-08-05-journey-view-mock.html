A push can never lie about progress

Drawn from the repo at cec06b1 · 5 August 2026 · read-only — this page changes nothing

Current situation

  1. The drawn board only updates when someone remembers to run the commands — nothing forces it.
  2. A stale board reads exactly like a current one; a trusted picture can misstate where things stand.
  3. Human memory was the only protection, and it had already slipped in real sessions.
