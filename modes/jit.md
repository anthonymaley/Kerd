## Setup

- [ ] `/kerd:switch` in -- open session, set context
- [ ] State the goal in one line -- what outcome are we chasing

## Requirements

- [ ] `/kerd:capturerequirements` -- interview to lock MVP must-haves, defer the rest
- [ ] Name the first slice -- smallest valuable thing to build and show

## Spec

- [ ] Write a thin spec -- just enough for the first slice, not exhaustive

## Build (loop per slice)

- [ ] Build the slice -- smallest valuable increment, TDD where it fits
- [ ] Show it -- you eyeball the slice and call it: go or revise
- [ ] Learn and revise -- wrong slice? update requirements + spec, reslice. Right? next slice.

## Close

- [ ] `/kerd:slainte` -- run docs and structural health checks
- [ ] `/kerd:switch` out -- close session, persist handoff context
