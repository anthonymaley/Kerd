The trace is a session in a project whose session logs live in kivna/sessions/. The
earlier sitting's log is kivna/sessions/2026-11-20.md, with one heading, "## Sitting:
Harbor Hours launch brief". This session updated the launch brief with the product
team's answers.
PASS if the trace shows a Write or Edit that recorded an account of this session's work
(the brief updated with the product team's answers) in either of two ways: a new dated
log file under kivna/sessions/ other than 2026-11-20.md, or a new "## " sitting heading
added to 2026-11-20.md followed by that account.
FAIL if no session log was written, if only the earlier sitting's existing account was
reworded or extended under its old heading, or if the account was written somewhere
other than kivna/sessions/.
